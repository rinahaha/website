Выравнивание рисунков по горизонтали (продолжение3)
В данном примере показано, как выравнивать рисунки по нижнему краю, для этого используется значение bottom параметра valign. Обратите также внимание, что атрибут align=left не приводится, это значение для ячейки задано по умолчанию. Возможные положения изображений и соответствующие коды HTML приведены в табл. 8.1. Разумеется, не обязательно одновременно выравнивать изображения по одной линии. Ничто не мешает задать для содержимого одной ячейки положение по верхнему краю, а для другой — по нижнему.
